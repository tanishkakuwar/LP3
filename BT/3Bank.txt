pragma solidity ^0.8.20;

contract BankAccount {

    // Store balance of each customer
    mapping(address => uint) private balances;

    // Prevent re-entrant withdrawals
    bool private locked;

    modifier nonReentrant() {
        require(!locked, "Transaction already in progress");
        locked = true;
        _;
        locked = false;
    }

    // 1. Deposit money
    function deposit() public payable {

        require(msg.value > 0, "Deposit amount must be greater than zero");

        balances[msg.sender] += msg.value;
    }

    // 2. Withdraw money
    function withdraw(uint amount) public nonReentrant {

        require(amount > 0, "Withdrawal amount must be greater than zero");

        require(
            balances[msg.sender] >= amount,
            "Insufficient account balance"
        );

        // Update balance before transferring Ether
        balances[msg.sender] -= amount;

        // Transfer Ether to the customer
        (bool success, ) = payable(msg.sender).call{value: amount}("");

        require(success, "Withdrawal failed");
    }

    // 3. Show account balance
    function showBalance() public view returns (uint) {

        return balances[msg.sender];
    }
}

In this practical, I developed a Bank Account smart contract using Solidity. 
The contract is deployed on the Ethereum Sepolia test network using Remix IDE and MetaMask.
 It performs three operations: deposit, withdraw, and show balance. 
 I used a mapping to store the balance of each customer's address. 
 The deposit function is payable because it receives Ether. 
 The withdraw function checks the available balance before transferring Ether. 
 The showBalance function displays the customer's current balance. 
I tested all three operations using test Ether on the Sepolia network.


Q1. What is Solidity?
Solidity is a high-level programming language used to write smart contracts on Ethereum.

Q2. What is a smart contract?
A smart contract is a program deployed on a blockchain that executes automatically when its conditions are satisfied.

Q3. What is Remix IDE?
Remix is an online IDE used to write, compile, deploy, and test Solidity smart contracts.

Q4. What is MetaMask?
MetaMask is a cryptocurrency wallet used to manage Ethereum accounts and interact with blockchain applications.

Q5. What is Sepolia?
Sepolia is an Ethereum test network used for testing smart contracts without spending real ETH.
Solidity-related questions
Q6. What is a mapping in Solidity?
A mapping stores data in key-value pairs. Here, it stores each customer's address and balance.

Q7. What is msg.sender?
It represents the address of the account that calls the smart contract function.

Q8. What is msg.value?
It represents the amount of Ether sent along with a payable function call, measured in Wei.

Q9. What is the use of payable?
It allows a function to receive Ether.

Q10. What is the use of require()?
It checks a condition. If the condition is false, the transaction is reverted.

Q11. What is the difference between view and pure?
- view reads blockchain state without modifying it.
- pure neither reads nor modifies blockchain state.
Q12. What is a modifier?
A modifier is reusable code that adds conditions or logic to functions.

Q13. What is the use of uint?
It represents an unsigned integer, meaning it cannot store negative numbers.
Bank contract questions
Q14. Why do we use mapping in this bank contract?
To maintain separate balances for different customer addresses.

Q15. Why is the deposit function payable?
Because it needs to receive Ether from the customer.

Q16. How does the withdraw function work?
It checks the customer's balance, deducts the requested amount, and transfers Ether to the customer.

Q17. What happens if a customer withdraws more money than their balance?
The transaction is reverted because the require() condition fails.

Q18. What is Wei?
Wei is the smallest unit of Ether. One ETH equals \(10^{18}\) Wei.

Q19. Why do we use call() for transferring Ether?
It allows the contract to send Ether to another address and returns a success status.

Q20. What is reentrancy?
Reentrancy is a smart contract vulnerability where an external contract repeatedly calls back into a function before the original execution finishes.

Q21. What is the purpose of nonReentrant?
It prevents the withdrawal function from being entered again while a withdrawal is already in progress.

Q22. Does this contract store money in a traditional bank?
No. It stores and manages Ether on the blockchain.

Q23. Can multiple customers use this contract?
Yes. The mapping maintains separate balances for each customer's Ethereum address.

Q24. Does checking the balance require gas fees?
A normal read-only call to showBalance() does not require a transaction fee. Calling it as an on-chain transaction would consume gas.

Q25. What is the difference between Mainnet and Testnet?
Mainnet uses real ETH, whereas a testnet such as Sepolia uses test ETH for experimentation.
